# Meu Study Hub TI

Repositório acadêmico e profissional de **Bruno de Lima Marques**, estudante de Ciência da Computação. Aqui organizo o que estudo, as entregas das disciplinas e os projetos que construo ao longo do curso.

**Página publicada (GitHub Pages):** https://brunolmars.github.io/Meu_Study_Hub_TI/

## Sobre o projeto

O Study Hub nasceu da atividade do Bootcamp I e serve para:

- organizar a produção acadêmica de forma padronizada;
- registrar a evolução nas áreas de maior interesse;
- praticar versionamento com Git e GitHub;
- compor um portfólio público para estágio e emprego na área de TI.

## Áreas de interesse

- **Desenvolvimento back-end com Java:** APIs, regras de negócio e bancos de dados.
- **Análise de dados:** identificar padrões e apoiar decisões.
- **Cibersegurança:** proteção de sistemas, dados e usuários.

## Como visualizar a página

1. Acesse o link do GitHub Pages acima; ou
2. Clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/brunolmars/Meu_Study_Hub_TI.git
cd Meu_Study_Hub_TI
```

## Versionamento

O projeto usa Git com commits curtos e descritivos, e tags para marcar as versões:

```bash
git add .
git commit -m "feat: página inicial v1.0"
git tag v1.0
git push origin main --tags
```

| Versão | Descrição                                      |
| ------ | ---------------------------------------------- |
| v1.0   | Primeira versão da página inicial do Study Hub |
